# 记账本

导入微信、支付宝账单，自动归类，并提供消费日历和统计分析。

## 运行环境

使用 conda 环境 `app`：

```bash
"D:/ProgramData/anaconda3/envs/app/python.exe" main.py
```

> 不要用 `conda activate app && python main.py`，直接指定 python 解释器路径。

服务启动后会自动打开浏览器，默认地址：

```
http://127.0.0.1:5000
```

## 导入账单

### 支持格式

| 平台 | 文件格式 | 备注 |
|------|----------|------|
| 微信 | `.xlsx` | 微信支付账单明细 |
| 支付宝 | `.csv` | GBK 编码的交易明细 |

### 操作步骤

1. 进入**交易明细**页面
2. 点击右上角的“导入账单”
3. 选择微信 `.xlsx` 或支付宝 `.csv` 文件
4. 系统会自动去重（按交易单号），并尝试按规则分类

导入后若出现“待分类”交易，可在交易明细中手动修改类别，或到**分类规则**页面添加自动规则后点击“重新归类”。

## 功能模块

### 交易明细

- 按月份、类别、来源、关键词筛选
- 点击交易可编辑类别、金额、描述、支付方式
- 编辑时可勾选“同时添加规则”，让相同关键词今后自动归类
- 支持手动新增支出记录

### 消费日历

- 选择月份，查看每天消费总额和笔数
- 点击日期可查看当天明细

### 统计分析

- 月度消费对比（柱状图）
- 月度趋势 + 3 月均线（折线图）
- 类别占比（环形图）
- 商家 / 交易对方 Top 10（横向条形图）
- 周内分布（柱状图）
- 支付方式分布（饼图）

可通过“起始月份”和“结束月份”筛选统计范围。

### 分类规则

- 添加关键词 → 类别的自动归类规则
- 支持启用/禁用、调整优先级、删除
- 修改规则后点击“重新归类”，会批量更新所有非手动指定的交易
- 可点击“导出 Excel 备份”保存配置（见下文「数据备份」）

### 类别管理

- 新增、重命名消费类别
- 若类别仍被交易使用，需先修改交易分类才能删除
- 可点击“导出 Excel 备份”保存配置（见下文「数据备份」）

## 数据备份

在「分类规则」或「类别管理」页面点击“⬇ 导出 Excel 备份”，浏览器会下载一份 Excel 文件（文件名带日期，如 `记账配置备份_2026-08-29.xlsx`），内含两个工作表：

| 工作表 | 列 |
|--------|-----|
| 类别管理 | 一级分类 / 二级分类 / 交易笔数 |
| 分类规则 | 排序 / 关键词 / 一级分类 / 二级分类 / 状态（启用/停用） |

建议在修改类别或规则后及时导出保存，防止本地数据遗失。

## 数据存储

SQLite 数据库文件位于：

```
data/account.db
```

首次运行会自动创建数据库和默认类别。

## 离线图表

统计分析使用 ECharts。首次部署时请确保 `static/echarts.min.js` 存在；若缺失，执行：

```bash
"D:/ProgramData/anaconda3/envs/app/python.exe" -c "
import urllib.request
url = 'https://cdn.jsdelivr.net/npm/echarts@5.4.3/dist/echarts.min.js'
out = 'static/echarts.min.js'
urllib.request.urlretrieve(url, out)
print('已保存', out)
"
```

项目以调试模式运行（`debug=True`），修改 Python 代码会自动重载，模板/静态文件也已加版本号防缓存，改动后刷新浏览器即可生效。
